# RAMZY — The Rift

بازی وب رترو با React 19، TypeScript و **Phaser 3.90**. بوم واقعی **1920×1080** است و فیزیک در مختصات 960×540 اجرا و با بزرگ‌نمایی دقیق 2× رندر می‌شود. رابط و تصویر منوی ارسالی، تمام فضای بازی را می‌پوشانند. روی نمایشگرهای دیگر نسبت 16:9 حفظ می‌شود.

## GitHub Pages

بازی: **https://ahmadramzy1.github.io/Ramzy-The-Rift-Game/**

انتشار خودکار با `.github/workflows/pages.yml` انجام می‌شود. هر push روی `main`، وابستگی‌ها را نصب می‌کند، تست‌ها را اجرا می‌کند و نسخهٔ نهایی را روی Pages منتشر می‌کند. اجرای دستی هم از Actions → Deploy game to GitHub Pages → Run workflow ممکن است.

در Settings → Pages، گزینهٔ Source باید **GitHub Actions** باشد. مسیر پروژه در دستور `npm run build:pages` تنظیم شده است؛ فونت‌ها، موسیقی، ویدیو و اسپرایت‌ها همراه بازی منتشر می‌شوند.

برای بررسی خروجی Pages در محیط محلی:

```sh
npm ci
npm test
npm run build:pages
npm run check:pages
npm run preview
```

در پیش‌نمایش، مسیر `/Ramzy-The-Rift-Game/` را باز کنید. پیشرفت و تنظیمات ذخیره‌شده به دامنهٔ مرورگر وابسته‌اند؛ ذخیرهٔ نسخهٔ قبلی روی دامنهٔ ChatGPT به Pages منتقل نمی‌شود.

## اجرا

Node.js 22.12+ یا 24 نصب باشد. در پوشهٔ پروژه:

```sh
npm install
npm run dev
```

نشانی محلی چاپ‌شده را باز کنید. برای نسخهٔ نهایی:

```sh
npm run build
npm run preview
```

پوشهٔ `dist` خروجی استاتیک قابل میزبانی است. فایل `index.html` را با دوبار کلیک و `file://` اجرا نکنید؛ سرور محلی لازم است. اسکریپت‌های ویندوز `Start-Game.cmd` و `Start-Built-Game.cmd` نیز همین کار را انجام می‌دهند.

## بازی

- **PLAY** نقشه را باز می‌کند. شروع تازه فقط مرحلهٔ ۱ را باز دارد. کامل‌کردن هر مرحله بعدی را آزاد می‌کند. پیشرفت و تنظیمات صوتی در مرورگر ذخیره می‌شوند.
- حرکت: ← → یا A/D؛ دویدن: Shift/X؛ پرش: Space/W/↑؛ فشار دوباره در هوا: دابل‌جامپ؛ کروچ: ↓/S.
- دو سلاح: ۱ تیرکمان، ۲ شمشیر، E تعویض. کلیک یا F حمله می‌کند. تیرکمان برد ۲۵۰ و آسیب ۱ HP؛ شمشیر برد ۷۸ و آسیب ۲ HP. حالت دست و چرخش شمشیر با ضربه هماهنگ است. stomp دو HP کم می‌کند.
- Q: کنترل ذهنیِ نزدیک‌ترین دشمن در برد ۴۸۰؛ بلندکردن و انفجار. یک شارژ برای هر تلاش مرحله، پس از مرگ شارژ نمی‌شود. بدون هدف مصرف نمی‌شود.
- P/Esc: توقف؛ R: شروع دوباره. باتری سبز بزرگ‌شدن و جذب یک ضربه؛ سه قلب، سه جان، چک‌پوینت و دو نوار مخفی در هر مرحله.
- دشمن‌ها HP متفاوت، گشت، تشخیص دید، تعقیب، هشدار کوتاه و حمله دارند. برخی تیر پرتاب می‌کنند. سرعت، HP، تعداد، شکاف‌ها و موانع به‌تدریج افزایش می‌یابند.
- پایان هر مرحله Eleven با ظاهر فصل پنجم وارد تصویر می‌شود، تشکر می‌کند، خارج می‌شود و نقشه با مرحلهٔ بعدیِ بازشده نمایش داده می‌شود.
- **SETTINGS**: Independent saved SFX/music volume. The user-supplied Stranger Things Theme Song C418 REMIX plays across menus and gameplay with loop crossfades. Stage starts fade and restart the track. Audio begins after the first user interaction.
- PLAY درخواست تمام‌صفحه می‌دهد. اگر مرورگر اجازه ندهد، بازی همچنان کل صفحهٔ در دسترس را می‌پوشاند. از دکمهٔ تمام‌صفحه در تنظیمات هم می‌توان استفاده کرد.

## کنترلر استاندارد

استیک چپ/D-pad: حرکت و کروچ؛ A/×: پرش؛ X/□ یا RT/R2: حمله؛ LB/L1: تعویض سلاح؛ Y/△: قدرت ذهنی؛ B/○ یا RB/R1: دویدن؛ Start/Options: توقف. در منوها جهت‌ها جابه‌جا، A تأیید و B بازگشت است. یک دکمه بزنید تا مرورگر کنترلر را شناسایی کند. نگاشت کنترلر آزمون خودکار دارد؛ سخت‌افزار واقعی در این محیط در دسترس نبود.

## مرحله‌ها و دارایی‌ها

محله، جنگل، آرکید، مدرسه، معدن، آزمایشگاه، تونل، بعد دیگر، طوفان پورتال، دروازهٔ نهایی. تعریف داده‌ها در `src/game/levels.ts`؛ حرکت در `mechanics.ts`، مبارزه در `combat.ts`، صدا در `audio.ts`، روند قفل‌ها در `progression.ts` و موتور در `GameScene.ts`.

هر پنج PNG اصلی ارسالی در `public/assets/source` حفظ شده‌اند. PNGهای سه مسیر `/mnt/data/...` در محیط موجود نبودند؛ به‌جای آن از فایل‌هایی که کاربر سپس فرستاد استفاده شده است. ۲۱ فریم قهرمان، ۲۰ فریم دشمن و ۳۶ قطعهٔ محیط با حفظ آلفای واقعی جدا شدند؛ فریم‌های نامنظم با مقیاس ثابت و لنگر پا هم‌تراز شده‌اند. منوی RAMZY عین تصویر ارسالی با دکمه‌های واقعی روی آن است. اطلاعات برش‌ها: `public/assets/manifest.json` و `scripts/prepare-assets.py`؛ برگهٔ بررسی: `docs/contact-sheet.png`.

تصویر Eleven S5 تازه با ابزار داخلی تولید تصویر ساخته شده و فایل نهایی در `public/assets/eleven-s5.png` است. مشخصات و منابع تحقیق در `docs/research.md` ثبت شده‌اند. هیچ نقشه، کد یا دارایی بازی‌های نینتندو کپی نشده است. فونت‌های محلی Vazirmatn و Press Start 2P همراه مجوز OFL هستند.

## بررسی

```sh
npm test
npm run build
```

آزمون موتور واقعی: هنگام اجرای سرور، `/tests/harness.html` و دکمهٔ Run engine tests. ده بررسی واقعی Phaser شامل برخورد زمین، کروچ، پرش دوبل، تیر و HP، شمشیر، پاک‌شدن قفل حرکت هنگام رفتن به مرحلهٔ دوم، قدرت ذهنی، چک‌پوینت، شروع ایمن ده مرحله و عبور فیزیکی از شکاف‌ها/دروازهٔ مرحلهٔ اول. دشمن‌ها فقط در تست مسیر برای جداکردن هندسه از مبارزه غیرفعال می‌شوند. تست مبارزه مجزا با دشمن زنده انجام می‌شود. `/tests/cinematic.html` بررسی سکانس واقعی پایان است. این صفحه‌های بررسی در build نهایی منتشر نمی‌شوند. `scripts/validate-assets.py` نیز لنگر فریم‌ها، درز زمین و آلفای پایهٔ اشیا را کنترل می‌کند.

مراحل در مرورگر و ابزار بررسی موتور آزمایش شده‌اند؛ درجهٔ دشواری هنوز می‌تواند با بازخورد بازیکن تنظیم شود.
