# RAMZY — The Rift

بازی وب رترو با React 19، TypeScript و **Phaser 3.90**. بوم واقعی **1920×1080** است و فیزیک در مختصات 960×540 اجرا و با بزرگ‌نمایی دقیق 2× رندر می‌شود. رابط و تصویر منوی ارسالی، تمام فضای بازی را می‌پوشانند. روی نمایشگرهای دیگر نسبت 16:9 حفظ می‌شود.

## GitHub Pages

بازی: **https://ahmadramzy1.github.io/Ramzy-The-Rift-Game/**

انتشار خودکار با `.github/workflows/pages.yml` انجام می‌شود. هر push روی `main`، وابستگی‌ها را نصب می‌کند، تست‌ها را اجرا می‌کند و نسخهٔ نهایی را روی Pages منتشر می‌کند. اجرای دستی هم از Actions → Deploy game to GitHub Pages → Run workflow ممکن است.

در Settings → Pages، گزینهٔ Source باید **GitHub Actions** باشد. مسیر پروژه در دستور `npm run build:pages` تنظیم شده است؛ فونت‌ها، موسیقی، ویدیو و اسپرایت‌ها همراه بازی منتشر می‌شوند.

برای بررسی خروجی Pages در محیط محلی:

```sh
npm ci
npm test
npm run build:pages
npm run check:pages
npm run preview:pages
```

در پیش‌نمایش، مسیر `/Ramzy-The-Rift-Game/` را باز کنید. پیشرفت و تنظیمات ذخیره‌شده به دامنهٔ مرورگر وابسته‌اند؛ ذخیرهٔ نسخهٔ قبلی روی دامنهٔ ChatGPT به Pages منتقل نمی‌شود.

## اجرا

Node.js 22.12+ یا 24 نصب باشد. در پوشهٔ پروژه:

```sh
npm install
npm run dev
```

نشانی محلی چاپ‌شده را باز کنید. برای نسخهٔ نهایی:

```sh
npm run build
npm run preview
```

پوشهٔ `dist` خروجی استاتیک قابل میزبانی است. فایل `index.html` را با دوبار کلیک و `file://` اجرا نکنید؛ سرور محلی لازم است. اسکریپت‌های ویندوز `Start-Game.cmd` و `Start-Built-Game.cmd` نیز همین کار را انجام می‌دهند.

## بازی

- **PLAY** نقشه را باز می‌کند. شروع تازه فقط مرحلهٔ ۱ را باز دارد. کامل‌کردن هر مرحله بعدی را آزاد می‌کند. پیشرفت و تنظیمات صوتی در مرورگر ذخیره می‌شوند.
- حرکت: ← → یا A/D؛ دویدن: Shift/X؛ پرش: Space/W/↑؛ پرش اول از زمین؛ پرش دوم فقط پس از خرید دائمی، با کول‌داون ۱۰ ثانیه. پس از قدم‌زدن از لبه، پرش فعال نمی‌شود؛ کروچ: ↓/S.
- دو سلاح: ۱ تیرکمان، ۲ شمشیر، E تعویض. کلیک یا F حمله می‌کند. تیرکمان برد ۲۵۰ و آسیب ۱ HP؛ شمشیر برد ۷۸ و آسیب ۲ HP. حالت دست و چرخش شمشیر با ضربه هماهنگ است. stomp دو HP کم می‌کند.
- Q: کنترل ذهنیِ نزدیک‌ترین دشمن در برد ۴۸۰؛ بلندکردن و انفجار. یک شارژ برای هر تلاش مرحله، پس از مرگ شارژ نمی‌شود. بدون هدف مصرف نمی‌شود.
- P/Esc: توقف؛ R: شروع دوباره. باتری سبز بزرگ‌شدن و جذب یک ضربه؛ سه قلب، سه جان، چک‌پوینت و دو رادیوی مخفی در هر مرحله.
- دشمن‌ها HP متفاوت، گشت، تشخیص دید، تعقیب، هشدار کوتاه و حمله دارند. برخی تیر پرتاب می‌کنند. سرعت، HP، تعداد، شکاف‌ها و موانع به‌تدریج افزایش می‌یابند.
- پایان هر مرحله Eleven با ظاهر فصل پنجم وارد تصویر می‌شود، تشکر می‌کند، خارج می‌شود و نقشه با مرحلهٔ بعدیِ بازشده نمایش داده می‌شود.
- **SETTINGS**: Independent saved SFX/music volume. The user-supplied Going Under / 8bit Stranger Things plays across menus and gameplay with loop crossfades. Stage starts fade and restart the track. Audio begins after the first user interaction.
- PLAY درخواست تمام‌صفحه می‌دهد. اگر مرورگر اجازه ندهد، بازی همچنان کل صفحهٔ در دسترس را می‌پوشاند. از دکمهٔ تمام‌صفحه در تنظیمات هم می‌توان استفاده کرد.

## کنترلر استاندارد

استیک چپ/D-pad: حرکت و کروچ؛ A/×: پرش؛ X/□ یا RT/R2: حمله؛ LB/L1: تعویض سلاح؛ Y/△: قدرت ذهنی؛ B/○ یا RB/R1: دویدن؛ Start/Options: توقف. در منوها جهت‌ها جابه‌جا، A تأیید و B بازگشت است. یک دکمه بزنید تا مرورگر کنترلر را شناسایی کند. نگاشت کنترلر آزمون خودکار دارد؛ سخت‌افزار واقعی در این محیط در دسترس نبود.

## مرحله‌ها و دارایی‌ها

محله، جنگل، آرکید، مدرسه، معدن، آزمایشگاه، تونل، بعد دیگر، طوفان پورتال، دروازهٔ نهایی. تعریف داده‌ها در `src/game/levels.ts`؛ حرکت در `mechanics.ts`، مبارزه در `combat.ts`، صدا در `audio.ts`، روند قفل‌ها در `progression.ts` و موتور در `GameScene.ts`.

هر پنج PNG اصلی ارسالی در `public/assets/source` حفظ شده‌اند. PNGهای سه مسیر `/mnt/data/...` در محیط موجود نبودند؛ به‌جای آن از فایل‌هایی که کاربر سپس فرستاد استفاده شده است. ۲۱ فریم قهرمان، ۲۰ فریم دشمن و ۳۶ قطعهٔ محیط با حفظ آلفای واقعی جدا شدند؛ فریم‌های نامنظم با مقیاس ثابت و لنگر پا هم‌تراز شده‌اند. منوی RAMZY عین تصویر ارسالی با دکمه‌های واقعی روی آن است. اطلاعات برش‌ها: `public/assets/manifest.json` و `scripts/prepare-assets.py`؛ برگهٔ بررسی: `docs/contact-sheet.png`.

تصویر Eleven S5 تازه با ابزار داخلی تولید تصویر ساخته شده و فایل نهایی در `public/assets/eleven-s5.png` است. مشخصات و منابع تحقیق در `docs/research.md` ثبت شده‌اند. هیچ نقشه، کد یا دارایی بازی‌های نینتندو کپی نشده است. فونت‌های محلی Vazirmatn و Press Start 2P همراه مجوز OFL هستند.

## بررسی

```sh
npm test
npm run build
```

آزمون موتور واقعی: هنگام اجرای سرور، `/tests/harness.html` و دکمهٔ Run engine tests. ده بررسی واقعی Phaser شامل برخورد زمین، کروچ، پرش دوبل، تیر و HP، شمشیر، پاک‌شدن قفل حرکت هنگام رفتن به مرحلهٔ دوم، قدرت ذهنی، چک‌پوینت، شروع ایمن ده مرحله و عبور فیزیکی از شکاف‌ها/دروازهٔ مرحلهٔ اول. دشمن‌ها فقط در تست مسیر برای جداکردن هندسه از مبارزه غیرفعال می‌شوند. تست مبارزه مجزا با دشمن زنده انجام می‌شود. `/tests/cinematic.html` بررسی سکانس واقعی پایان است. این صفحه‌های بررسی در build نهایی منتشر نمی‌شوند. `scripts/validate-assets.py` نیز لنگر فریم‌ها، درز زمین و آلفای پایهٔ اشیا را کنترل می‌کند.

مراحل در مرورگر و ابزار بررسی موتور آزمایش شده‌اند؛ درجهٔ دشواری هنوز می‌تواند با بازخورد بازیکن تنظیم شود.

## دانجن، فروشگاه و ستاره‌ها

کنار ورودی سنگی هر مرحله، روی زمین بایستید و ↓ یا S بزنید (کنترلر: D-pad پایین؛ لمسی: کروچ). داخل دانجن دشمن‌ها بیشتر و قوی‌ترند؛ تا همه شکست نخورند خروج نهایی باز نمی‌شود. کنار ورودی، ↑ یا ↓ برای عقب‌نشینی است. برای ثبت سه ستاره پس از پاک‌کردن دانجن، به انتهای مسیر اصلی برسید.

سکه‌ها در کیف پول مرورگر ذخیره می‌شوند. فروشگاه فقط این خریدها را دارد:

- جان اضافه: ۱۰۰ سکه، شروع مرحلهٔ انتخاب‌شده با ۴ جان؛ یک خرید برای هر شروع.
- شارژ ذهنی: ۵۰ سکه برای هر شارژ اضافه؛ قابل تکرار. شارژ پایهٔ هر مرحله یک است و مرگ شارژ مصرف‌شده را برنمی‌گرداند.
- پرش دوم: ۶۰ سکه، بازشدن دائمی؛ کول‌داون ۱۰ ثانیه پس از هر پرش دوم، حتی پس از فرود یا عوض‌شدن اتاق.
- تیرکمان: سطح ۲ با ۱۰۰ سکه، دو تیر با آسیب ۱ برای هر تیر؛ سطح ۳ با ۴۰۰ سکهٔ دیگر، دو تیر آتشین با آسیب ۲ برای هر تیر. ارتقا دائمی است.
- شمشیر افسانه‌ای: ۶۰۰ سکه، ظاهر بنفش در دست و آسیب ۶ به‌جای ۲؛ ارتقا دائمی است. جهت ضربه از محل کلیک موس تعیین می‌شود.

خرید جان و شارژ تا شروع مرحلهٔ انتخاب‌شده ذخیره می‌ماند. ارتقای سلاح و پرش دوم برای ادامهٔ بازی حفظ می‌شود. خریدهای قدیمیِ مصرف‌نشدهٔ انرژی/قدرت هنگام تبدیل ذخیره بازپرداخت می‌شوند. تعداد سکه‌های مسیر اصلی و دانجن ۱٫۵ برابر شده است. پس از شکست همهٔ دشمن‌های دانجن، سکهٔ آبی ۲x کنار خروج ظاهر می‌شود؛ برداشتن آن و برد مرحله، معادل سکه‌های جمع‌شدهٔ همان تلاش در مسیر اصلی و دانجن را یک‌بار به کیف پول اضافه می‌کند.

سلامتی پایهٔ دشمن‌های عادی ۲ HP بیشتر شده و از مرحلهٔ اول به ازای هر مرحله ۱ HP رشد می‌کند؛ سختی اضافهٔ دانجن نیز حفظ می‌شود. بیلی از مرحلهٔ دوم ۷ HP دارد و هر مرحله یک HP رشد می‌کند. در هر دو مسیر اصلی و دانجن: مرحلهٔ ۱ فقط crawler؛ مرحلهٔ ۲ به‌علاوهٔ bat؛ مرحلهٔ ۳ به‌علاوهٔ husk و slime؛ از مرحلهٔ ۶ به‌علاوهٔ bloom و همهٔ پنج نوع. اطلس پیکسلی تازهٔ `public/assets/upgrade-atlas.png` با تولید تصویر ساخته شده؛ برش‌های زمان اجرا برای شمشیرهای داخل دست، تیرهای آتشین و سکهٔ ۲x هم استفاده می‌شوند.

بررسی متمرکز ارتقاها: `/tests/harness.html?upgradeOnly` چهار سناریوی واقعی Phaser را اجرا می‌کند؛ داده‌های ذخیرهٔ بازی را پس از اجرا برمی‌گرداند.

مایند فلِیر نزدیک دروازهٔ مرحلهٔ ۳ قرار دارد: ۳۰ HP ثابت و ارتفاع قابل‌دیدن ۱۳۶ پیکسل (دو برابر قهرمان عادی). اسپرایت چهارحالتهٔ `public/assets/mind-flayer.png` از تصویر مرجع کاربر تولید شده است. هر ۵ ثانیه دو موج زمینی به طرفین می‌فرستد؛ ۶۵۰ میلی‌ثانیه پیش از کوبش دست‌ها را بالا می‌برد. برخورد موج روی همان سطح ۲ قلب کم می‌کند، از سپر بزرگ‌شدن عبور می‌کند و زمان مصونیت معمول را رعایت می‌کند. پرش و سکوهای بالاتر ایمن هستند؛ موج در شکاف یا لبهٔ سطح متوقف می‌شود. مرگ یا کنترل ذهنی باس موج‌های باقی‌مانده را متوقف می‌کند. بررسی موتور: `/tests/harness.html?bossOnly`.

موج‌ها از اطلس پیکسلیِ تولیدشدهٔ `public/assets/psychic-shockwave.png` استفاده می‌کنند: چهار فریم انرژی سرخ و بنفش، هستهٔ روشن، دنباله و ذرات روی زمین. خط تماس تصویر دقیقاً روی سطح و جبههٔ روشن کنار محدودهٔ برخورد قرار دارد؛ جهت چپ قرینه است. کاهش حرکت، انیمیشن و ذرات اضافه را متوقف می‌کند و حرکت اصلی موج را حفظ می‌کند.

بیلی روی ویلچر، از مرحلهٔ ۲ به بعد روی دو سکوی مرتفع مسیر اصلی قرار دارد؛ از ۷ HP شروع می‌کند و هر مرحله یک HP بیشتر دارد و حرکت یا تعقیب نمی‌کند. اسپرایت چهارحالتهٔ `public/assets/billy-wheelchair.png` از عکس کاربر ساخته شده است. در حالت بیکار انیمیشن خنده و افکت خندهٔ رترو دارد. در برد ۵۴۰، هر ۴ ثانیه مولوتوف قوسی پرتاب می‌کند؛ ۳۵۰ میلی‌ثانیه پیش از پرتاب بطری را بالا می‌برد. بطری پس از برخورد آتش کوتاهی به مدت ۲٫۴ ثانیه روی سطح باقی می‌گذارد. مدکیت‌ها با `medkitPlacement` روی سطح قابل‌دسترسی و بیرون سکوها قرار می‌گیرند؛ در سلامت کامل مصرف نمی‌شوند. بررسی واقعی موتور: `/tests/harness.html?billyOnly`.

دانجن مرحلهٔ ۵ چهار نگهبان و یک وکنا در انتهای مسیر دارد. وکنا ۱۰ HP ثابت و ارتفاع عادیِ قابل‌دیدنِ ۲۰۴ پیکسل، سه برابر قهرمان، دارد؛ تصویر چهارحالتهٔ `public/assets/vecna.png` از منابع کاربر تولید شده است. وقتی قهرمان وارد میدان نهایی شود، هر ۳ ثانیه خشمگین می‌شود و می‌پرد؛ نشان قرمز ۵۰۰ میلی‌ثانیه پیش از پرش روی موقعیت قهرمان قفل می‌شود. پرش ۹۰۰ میلی‌ثانیه طول می‌کشد. فرود در محدوده ۳ قلب کم می‌کند و سپر بزرگ‌شدن را کنار می‌زند؛ حرکت از نشان یا پرش بلند راه جاخالی است. خروجی دانجن تا شکست باس و نگهبان‌ها قفل می‌ماند. بررسی موتور: `/tests/harness.html?vecnaOnly`.

تصاویر مخصوصِ گرفتن سلاح در `public/assets/held-weapons.png` تولید شده‌اند: تیرکمان چوبی/آتشین و شمشیر فولادی/بنفش، هرکدام با دست روی قبضه. تیرکمان عمودی می‌ماند؛ هر دو سلاح به محل مشت اصلی در هرکدام از ۲۱ فریم قهرمان متصل‌اند و بازوی اضافه روی بدن رسم نمی‌شود. شمشیر هنگام حمله از همان مچ می‌چرخد. محل اتصال و خروج تیر در `weaponPose.ts` محاسبه می‌شود.

یک ستاره: پایان مرحله؛ دو ستاره: پایان مرحله همراه همهٔ سکه‌ها و رادیوهای مسیر اصلی؛ سه ستاره: پاک‌کردن دانجن و سپس پایان مرحله. بهترین رکورد حفظ می‌شود. سکه‌های دانجن پاداش جداگانهٔ کیف پول‌اند.

Music playlist: Going Under (Remastered) and 8bit Stranger Things. Settings select the starting track and persist it as ramzy-music-track. The transport alternates both tracks indefinitely with crossfades; stage starts restart the selected track. Independent music/SFX volumes remain available.
